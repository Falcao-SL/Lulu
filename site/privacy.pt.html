O que fica neste Mac.

Vigente em 16 de novembro de 2026. Vale para o app Lulu para macOS, da Falcao SL. Dúvidas: dev@falcaosl.com.

Neste Mac

  • Modelos em ~/models/mlx e ~/models/gguf.
  • Sessão e logs em ~/.lulu/.
  • O token opcional do Hugging Face e a chave do servidor local, no Keychain do macOS.

O servidor local

O servidor escuta só em 127.0.0.1. Perguntas e respostas desse servidor ficam no Mac. O llama.cpp sobe com a chave do Keychain. O mlx-lm e o mlx-vlm sobem sem essa flag. Os clientes que o Lulu configura recebem a mesma chave.

Quando a rede é usada

  • Buscar e baixar modelos fala com o Hugging Face.
  • Instalar um motor usa Homebrew ou uv, ou abre o download do próprio fabricante.
  • Checar atualizações, o que você começa na tela Overview, pergunta ao GitHub qual é a release mais recente. Instalar essa release usa o Sparkle e o appcast assinado deste site.

O app não tem SDK de analytics nem relatório de falhas. O Sparkle está com checagem automática desligada e sem envio de perfil do sistema. O Lulu não pede conta.

Este site

lulu.falcaosl.com é um site estático. Não grava cookie de rastreamento e não carrega script de analytics. Os downloads vão para o GitHub Releases.
