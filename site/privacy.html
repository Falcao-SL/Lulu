What stays on this Mac.

Effective 16 November 2026. This covers the Lulu macOS app from Falcao SL. Questions: dev@falcaosl.com.

On this Mac

  • Models in ~/models/mlx and ~/models/gguf.
  • Session data and logs in ~/.lulu/.
  • An optional Hugging Face token, and the local server key, in macOS Keychain.

The local server

The server listens on 127.0.0.1 only. Prompts and responses for that server stay on the Mac. llama.cpp is started with the Keychain key. mlx-lm and mlx-vlm are started without that flag. Clients that Lulu configures receive the same key.

When the network is used

  • Searching and downloading models talks to Hugging Face.
  • Installing an engine uses Homebrew or uv, or opens the publisher's own download.
  • Check for updates, which you start from Overview, asks GitHub for the latest release. Installing that release uses Sparkle and the signed appcast on this site.

There is no analytics SDK and no crash reporter in the app. Sparkle is set with automatic checks off and system-profile sending off. Lulu does not ask you to create an account.

This website

lulu.falcaosl.com is a static site. It does not set a tracking cookie and it does not load an analytics script. Downloads go to GitHub Releases.
